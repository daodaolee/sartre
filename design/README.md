# Design sources

This directory preserves editable product design sources that support Sartre
implementation and review.

## Pencil source

- `pencil/sartre-product-v2.pen` is the editable Sartre product design source.
- Imported on 2026-07-24 from the working file `untitled.pen`.
- Source SHA-256:
  `52cb7849746fe0f15ce7e597d40da75faca3f5a88eb137c9d65984a1128af881`.
- The document uses Geist, Geist Mono, and JetBrains Mono.

Open the `.pen` file in Pencil and save changes back to the same path so Git
can preserve its history. Put generated previews or handoff exports under
`design/exports/` only when they are intentionally selected for review.

Design files are supporting product artifacts. They do not override the
repository authority order defined by `AGENTS.md`; implementation decisions
remain governed by `spec/`, then `workflow/`, then `plan/`.
